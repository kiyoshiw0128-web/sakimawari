# 評価キット(sakimawari)

スキルを変えたときに、悪くなっていないかを確かめるための一式。

## 中身

| ファイル | 内容 |
|---|---|
| `cases/` | テスト資料。A〜J は穴を仕込んだ合成資料(E・I・J は穴の少ない資料)。L は資料に指示が紛れた例、M はコード(対象外)。 |
| `truth.json` | 正解データ。仕込んだ穴の位置(引用)と重さ、「すでに答えている」箇所。 |
| `run_iter.py` | 各資料を、独立した `claude -p` で実行する。指示文とスキルを system prompt として渡し、Copilot の構成を模擬する。 |
| `score.py` | 採点。引用が原文と一致するか、形式、仕込んだ穴を見つけたか、穴のない資料での警報などを数える。 |
| `compare.py` | 版ごとの結果を並べる。 |
| `結果_2026-10-21.md` | 初回の評価の記録。 |

## 使い方

```
python3 run_iter.py <実行名> <スキルのフォルダ> <指示文のファイル> --model sonnet --reps 2
python3 score.py <実行名> --detail
```

- `claude` コマンド(Claude Code)が要る。
- 出力は `runs/<実行名>/` に保存される。
- 内容の妥当性(質問が本当に聞かれそうか)は、スクリプトでは分からない。出力を読んで判断する。
- Copilot で試した結果は、`cases/` に追加し、`truth.json` に正解を足すと、同じ形で比べられる。
