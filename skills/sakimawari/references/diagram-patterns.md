# 図の型

言葉だけでは関係が追いにくいときに、図を付ける。簡単な指摘には付けない。

## 付けるとき

- 複数の箇所にまたがる話: 食い違い、つながらない、対応がずれる。
- 手順や条件の分かれ道。
- 数の対応: 課題の数と施策の数が合わない、など。
- 全体の見取り図: 資料の流れと、質問が出る箇所。

## 作り方

- 箱で囲まず、縦に流れる文字の図にする。全角の文字は幅がそろわないので、枠線をそろえる図は崩れる。
- 行頭の記号（│ ├─ └─ ▼ ↕）と矢印で、流れと分かれ道を示す。
- 質問が出る箇所には、行の最後に「← Q1」のように印をつける。
- 各質問の図は6行以内、見取り図は10行以内にする（空行を除く）。
- 図の中の言葉は、資料のものをそのまま使う。資料にない事実や数字を、図に書かない。
- 図は、コードブロック（```）に入れる。

## 型

### つながらない（根拠から結論に飛ぶ）
```
根拠：（資料の言葉）
   │
   ├─ ？ ← このつながりが書かれていない
   ▼
結論：（資料の言葉）
```

### 食い違い（2か所が合わない）
```
（位置1）：（資料の言葉）
   ↕ 食い違っていないか？
（位置2）：（資料の言葉） ← 何で成り立つかが書かれていない
```

### 分かれ道（条件の境目が決まっていない）
```
問い：（資料の言葉）
   ├─ はい → （次の行き先）
   └─ いいえ → （次の行き先）
   ※「（境目の言葉）」の基準が書かれていない
```

### 対応のずれ（課題と施策の数が合わない）
```
課題A ──▶ 施策1
課題B ──▶ （対応なし） ← 誰が対応する？
課題C ──▶ 施策2
```

### 全体の見取り図（資料の流れと、質問が出る箇所）
```
1枚目  （資料の言葉）            ← Q2
2枚目  （資料の言葉）            ← Q5
3枚目  （資料の言葉）            ← Q3
 ...
10枚目 （資料の言葉）            ← Q4
```
