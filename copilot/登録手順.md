# Microsoft 365 Copilot への登録手順（sakimawari）

作成日: 2026-10-20

## 使うファイル

| ファイル | 内容 |
|---|---|
| `エージェント指示文.md` | エージェントの「指示」欄に貼る文章（約5,000字。上限は8,000字） |
| `dist/sakimawari.zip` | エージェントに追加するスキル。`python3 scripts/build_copilot_zip.py` で作る（`SKILL.md` が ZIP の直下にある） |

## 前提（Microsoft の資料による）

- Agent Builder のカスタムスキルはプレビュー機能で、Microsoft Frontier プログラムに登録された組織だけが使える。
- 対象となる Microsoft 365 Copilot ライセンス（または従量課金）が必要。
- Microsoft Purview の情報バリア（Information Barriers）を使うテナントでは、カスタムスキルを使えない。
- 現時点では、スキルと「埋め込みファイル」を同じエージェントで併用できない。
- 職場のテナントで使えるかは、管理者に確認する。

## 手順

1. Microsoft 365 Copilot のチャット（https://m365.cloud.microsoft ）を開き、「エージェント & スキル」から「新しいエージェント」を選ぶ。
2. エージェントの名前と説明を入れる（例は下）。
3. 「構成」タブの「指示」欄に、`エージェント指示文.md` の中身をそのまま貼る。
4. 同じ「構成」タブで「スキル」を展開し、「追加」を選ぶ。
5. `dist/sakimawari.zip` を、解凍せずにそのままアップロードする。`SKILL.md` だけをアップロードしない。
6. スキルの名前、説明、手順、含まれるファイルが表示されるので、内容を確認する。
7. 「試してみる」タブで、下の試験用の依頼を入れて動作を確かめる。

画面の名称は、日本語版の Microsoft Learn（機械翻訳）の表記による。画面と違う場合は、近い名前の項目を選ぶ。

## エージェントの名前・説明・開始用の例

- 名前: 先回りチェック
- 説明: 報告・提案・企画などの資料を出す前に、相手が聞きそうな質問を洗い出し、資料の直し方と答えの準備を提案する。
- 会話の開始用の例（スターター）:
  1. 「この資料の想定質問を出して」
  2. 「部長向けの提案資料です。出す前に、突っ込まれそうなところを教えて」
  3. 「突っ込まれそうなところと、答えの準備を教えて」

## 試験用の依頼（架空の資料）

次の文章を貼って、「相手: 部長、案件は初見、コストを気にする。想定質問を出して」と依頼する。

```
A/Bテストの結果、新しいデザインのほうがコンバージョン率が高かった。そのため、来月から全ページに新デザインを展開したい。
```

期待する動き:

- 「なぜ全ページに広げてよいと言える？」（飛躍または範囲の抜け）、「どれくらい高かった？ 何件で試した？」（比較対象・数字の出どころ）、「費用と工数は？」（実行面の抜け）が、重さの理由つきで出る。
- 資料にない数字や出典が、作られていない。
- 各質問に、資料の直し方と答えの準備が付く。
- 「本番前に調べておくこと」が別に出る。

## うまく動かないとき

- スキルが使われない: エージェントの指示に「スキル『sakimawari』に従う」と書かれているか確かめる。依頼に「想定質問」「突っ込まれそうなところ」などの言葉を入れる。
- 出力が長すぎる、または崩れる: 指示文の「出力の形式」を、より具体的にする（件数や項目数を指定する）。
- 事実が作られる: 指示文の「基本ルール」の2つ目を、文頭に移して強調する（`**` で囲む）。
- スキルを追加できない: 前提（Frontier プログラム、ライセンス、情報バリア）を管理者に確認する。

## 制限の確認（Microsoft の資料による）

| 項目 | 上限 | このスキルの値 |
|---|---|---|
| エージェントの指示の文字数 | 8,000字 | 約5,000字 |
| 1エージェントのスキル数 | 8 | 1 |
| スキルの ZIP | 50 MB | 約21 KB |
| 1ファイルの大きさ | 25 MB | 約21 KB 以下 |
| ZIP 内のファイル数 | 350 | 7 |
| ディレクトリの深さ | 3 | 1 |
| `SKILL.md` の文字数 | 20,000字未満 | 約8,400字 |
